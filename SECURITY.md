# Security policy

TyCHO writes HTML pages that run its JavaScript runtime in the reader's browser, and it reads scene and data files that may come from someone else. Report a vulnerability in either package privately, through GitHub's [private vulnerability reporting](https://github.com/beeson-group/tycho/security/advisories/new), not in a public issue, so that it can be fixed before it is disclosed.

Fixes go into the latest release only, and older releases do not receive them. Before 1.0, the latest release is the latest minor version with its patch releases, e.g. 0.2.x.
